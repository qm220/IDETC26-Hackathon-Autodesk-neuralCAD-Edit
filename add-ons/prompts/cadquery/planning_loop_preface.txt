The planning stage produced model.json (hierarchical part → sections → features
→ B-rep faces), aim.json (desired final state from the edit request), and
operation.json (grounded edit operations, parameters, constraints, targets,
and modeling plans). Use those artifacts when writing my_cad_function.

Section ids look like R01. Feature ids look like F001. FACE N values are
CadQuery Faces() indices from the STEP analysis. Bind them to actual STEP
geometry by inspecting the loaded model (print faces and coordinates) before
editing. If an operation needs boundary topology such as a chamfer or fillet
edge, derive it in CadQuery from the grounded face(s).

Implement each operation's modeling_plan steps. Load the start model from
args["input_file"].
